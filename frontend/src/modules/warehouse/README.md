# Модуль «Склад» — приёмка по файлу

Перенос приложения «Склад-приёмка» (Google Apps Script: `Code.gs` + `Index.html`) в хаб. Функционал повторён как в исходнике, дизайн — хаба (Trendsetter), расположение кнопок — как в исходном приложении.

## Что внутри
- `lib/` — чистая логика без React, перенесена из `Index.html` без изменений поведения, покрыта тестами (`npm test`):
  `marks.js` (Честный знак: разбор DataMatrix, раскладка клавиатуры, GTIN/EAN), `plan.js` (раскладка из Excel, маршрутизация по коробкам, режим «без ЧЗ»), `code128.js`, `csv.js`, `print.js` (этикетки 58×40 — вёрстка как в оригинале намеренно), `localBackend.js` (серверная часть).
- `store.js` — состояние и сценарии (скан, закрытие короба, приёмки, импорт…), как в исходнике живёт вне React; React перерисовывается по `emit()`.
- `components/`, `WarehousePage.jsx`, `warehouse.css`, `strings.js` — интерфейс.

## Данные: пока локально
Серверной части нет: `lib/localBackend.js` хранит данные в `localStorage` браузера (ключ `whf_store`). Единственный шов — функция `api(name, ...args)` в `store.js`.

## ПИН ответственного
В исходнике ПИН зашит в `Code.gs`. В репозитории настоящего ПИНа нет: для демо в `localBackend.js` стоит `DEMO_PIN`. В рабочей версии ПИН проверяет сервер.

## Исходные материалы
Лежат локально в `modules/warehouse/` (папка в `.gitignore`: в `Code.gs` ПИН и почты, в `links.txt` ссылки на таблицу). Передавать через общий диск.

## Зависимость
`xlsx@0.18.5` (SheetJS, та же версия, что в исходном приложении) — чтение Excel; грузится лениво при выборе файла. У этой версии есть известные замечания `npm audit`; обновление идёт только через CDN-сборку SheetJS.
