# Склад: проверка на реальном железе (WEEEK #18836)

Адрес: `https://hub.trendsettercrew.com` → модуль «Склад». Нужен вход сотрудником отдела «Склад» (или admin). Пока идёт проверка, **боевые приёмки не создавайте**: заведите тестовую приёмку с понятным именем (например «ТЕСТ железо 19.10») и в конце отметьте её в таблице результатов.

Что нужно на месте: ПК склада, принтер этикеток 58×40, сканер штрихкодов (режим «клавиатура», суффикс Enter), несколько реальных коробок/товаров, один настоящий .xlsx поставки (раскладка), 3–5 DataMatrix-кодов Честного знака (для режима ЧЗ).

Отмечайте в колонке «Результат»: ✅ работает / ❌ не работает (что именно) / ⚠️ работает с замечанием.

## 1. Вход и права
| Шаг | Ожидается | Результат |
|---|---|---|
| Войти сотрудником склада, открыть «Склад» | Открывается приёмка, внизу нет «только просмотр» | |
| Войти сотрудником другого отдела без группы | Склад открывается только на просмотр, сканировать нельзя | |
| Сотрудник другого отдела, добавленный админом в группу «Склад: запуск» | Через минуту (или после возврата на вкладку) Склад открывается на приёмку без перелогина | |
| Админ убирает его из группы | Через минуту Склад снова «только просмотр» | |
| Ответственный по группе: «Ещё» → доп. секции/импорт | Поле ПИН не показывается, действие проходит | |
| Обычный сотрудник склада: те же действия | Просит ПИН; неверный ПИН даёт «Неверный ПИН» | |

## 2. Чтение настоящего .xlsx (раскладка)
| Шаг | Ожидается | Результат |
|---|---|---|
| «Загрузить Excel» → реальный файл поставки | Открывается выбор листа и столбцов (штрихкод / номер коробки / количество / код ЧЗ) | |
| Столбцы угаданы верно | Подставлены автоматически; можно поправить вручную | |
| «Применить» | В шапке «Загружен …. Строк: N, коробок: M, ожидается штук: K» — числа совпадают с файлом | |
| Файл с кириллицей в имени, большой файл (несколько тысяч строк) | Грузится без зависания, без «файл не читается» | |
| Файл .xls и .csv (если используются) | Читается; кириллица в CSV не портится | |
| Загрузить раскладку на ПК 1, открыть Склад на ПК 2 | На ПК 2 появляется «новая раскладка» и кнопка «Обновить раскладку» | |

## 3. Сканер
| Шаг | Ожидается | Результат |
|---|---|---|
| Курсор в поле скана, отсканировать товар из файла | Звук OK, счётчик «отсканировано» +1, товар попадает в свою коробку | |
| Отсканировать товар, которого нет в файле | Попадает в «Нет в файле и излишки», сигнал ошибки | |
| Отсканировать тот же ШК дважды быстрее 2 с (защита включена) | Второй скан не засчитывается | |
| Раскладка клавиатуры русская при сканировании | Код читается верно (чинится раскладка), без «кракозябр» | |
| Режим «Честный знак»: DataMatrix | Код принимается один раз, повтор — отказ «уже принят» | |
| Тот же КИ на другом ПК | Отказ (защита кодов между ПК) | |
| Режим «Скан без ЧЗ» на маркированном товаре | Принимается по EAN, код ЧЗ не регистрируется | |
| Скан при потере сети (выдернуть кабель на 30 с, сканировать, вернуть) | Сканы не теряются; индикатор «ждут отправки: N», после возврата сети «✓ Всё в базе» | |
| Перезагрузить страницу (F5) в середине приёмки | Состояние и очередь сканов на месте | |

## 4. Короба, палеты, печать этикеток 58×40
| Шаг | Ожидается | Результат |
|---|---|---|
| «Тест этикетки» | Открывается окно печати, размер 58×40, текст и штрихкод не обрезаны | |
| Закрыть короб (автопечать включена) | Печатается этикетка: номер короба, секция/палет, штрихкод Code128 | |
| Считать напечатанный штрихкод сканером | Читается без ошибок; номер совпадает с интерфейсом | |
| «+ этикетка палета» | Вторая этикетка с номером палета | |
| «Этикетки открытых» / «Закрыть все» | Печатаются все открытые, без пропусков | |
| Постановка короба на хранение по ШК палета | Короб привязывается к палету, секции видны в «Хранение» | |
| Открыть закрытый короб повторно по ШК | Открывается с прежним номером и палетом | |
| Печать из Chrome и из Edge (какой используют на складе) | Одинаковый размер, нет полей/лишней страницы | |
