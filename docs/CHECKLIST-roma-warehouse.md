# Склад в хабе: проверка для Романа

Адрес: https://hub.trendsettercrew.com. Войдите своей почтой и паролем, откройте в меню «Приёмка (Склад)». Остальные пункты меню для вас закрыты, это нормально: там будет «Нет доступа».

**Главное правило: тренируйтесь только в тестовой приёмке.** Создайте приёмку с именем «ТЕСТ Роман 20.10» (дату поставьте свою) и работайте в ней. Приёмки «Новая Мода» и «Daisyknit» — это перенесённые боевые данные, в них ничего не сканируйте и не закрывайте.

Что нужно под рукой: ПК склада, принтер этикеток 58×40, сканер, несколько настоящих коробок с товаром, один .xlsx поставки, 3–5 кодов «Честного знака».

Отмечайте в колонке: ✅ работает, ❌ не работает (что именно), ⚠️ работает, но есть замечание.

## 1. Вход
| Что сделать | Что должно быть | Результат |
|---|---|---|
| Войти в хаб, открыть «Приёмка» | Открывается Склад, можно сканировать | |
| Нажать любой другой пункт меню (Отборка, Отчёты…) | Страница «Нет доступа» по центру, кнопка «На главную» | |
| Выйти и войти снова | Входит без ошибок | |

## 2. Приёмка и список поставки
| Что сделать | Что должно быть | Результат |
|---|---|---|
| Создать тестовую приёмку «ТЕСТ Роман …» | Появляется в списке, выбрана | |
| «Загрузить Excel», выбрать настоящий файл поставки | Откроется выбор листа и столбцов | |
| Проверить столбцы (штрихкод, номер коробки, количество, код ЧЗ), нажать «Применить» | В шапке строки, коробки и «ожидается штук» совпадают с файлом | |
| Файл на несколько тысяч строк | Грузится без зависания | |

## 3. Сканирование
| Что сделать | Что должно быть | Результат |
|---|---|---|
| Отсканировать товар из файла | Звук, счётчик +1, товар в своей коробке | |
| Отсканировать товар, которого нет в файле | Попадает в «Нет в файле и излишки», сигнал ошибки | |
| Дважды подряд быстро отсканировать один штрихкод | Второй раз не засчитывается | |
| Режим «Честный знак»: отсканировать код | Принимается один раз, повтор — отказ «уже принят» | |
| Отсканировать при русской раскладке клавиатуры | Код читается без «кракозябр» | |
| Нажать F5 посреди приёмки | Всё на месте, ничего не пропало | |
| Выдернуть сетевой кабель на 30 секунд, сканировать, вернуть кабель | Сканы не теряются; видно «ждут отправки», потом «Всё в базе» | |

## 4. Короба, палеты, этикетки
| Что сделать | Что должно быть | Результат |
|---|---|---|
| «Тест этикетки» | Печатается этикетка 58×40, текст и штрихкод не обрезаны | |
| Закрыть короб | Печатается этикетка: номер короба, секция/палет, штрихкод | |
| Считать штрихкод с этикетки сканером | Читается, номер совпадает с экраном | |
| «Этикетки открытых» / «Закрыть все» | Печатаются все, без пропусков | |
| Поставить короб на хранение по штрихкоду палета | Короб привязан к палету, виден в «Хранение» | |
| Открыть закрытый короб повторно по штрихкоду | Открылся с прежним номером | |
| Справа плитки секций: числа вида «3785/13286» | Помещаются в ячейку, не вылезают за рамку | |
| Печать из того браузера, которым пользуетесь на складе | Размер 58×40, нет лишней страницы | |

| Выгрузить по коробам и расхождения (.csv) | В Excel читается кириллица | |
| Завершить тестовую приёмку | Статус «завершена», новые сканы в неё не идут | |

## 6. Два компьютера (если есть возможность)
| Что сделать | Что должно быть | Результат |
|---|---|---|
| Два ПК сканируют одну приёмку в **разные** коробки | Номера коробов и палетов не повторяются | |
| Один и тот же код «Честного знака» на втором ПК | Отказ | |
| На втором ПК обновить страницу (F5) | Видны короба и итоги первого | |

Не сканируйте в один и тот же открытый короб с двух компьютеров: защиты от этого пока нет, договоритесь на словах. Сделаем отдельно.

## 7. Что писать, если что-то не так
Для каждого ❌ или ⚠️ пришлите: что делали, что увидели (скриншот или фото экрана), время, браузер, модель принтера и сканера. Пишите списком, из него заведём задачи.
