# Handoff: Trendsetter Hub — редизайн по брендбуку

## Overview
Внутренний модульный хаб Trendsetter: каждый отдел получает свой инструмент (модуль). Сейчас работает модуль «Закупки → Отборка» (автоотбор товара из прайса поставщика), остальные — ROADMAP. Задача — перенести существующий проект (trendsetter-hab.vercel.app) на новый визуальный язык из брендбука Trendsetter.

## About the Design Files
`Trendsetter Hub.dc.html` — **дизайн-референс в HTML**, прототип внешнего вида и поведения, а не production-код. Нужно **воссоздать этот дизайн в существующем кодовой базе проекта** (её фреймворк, роутинг, компоненты, API), сохранив текущую логику и данные. Файл открывается в браузере напрямую (рядом должен лежать `support.js`).

## Fidelity
**High-fidelity.** Цвета, шрифты, отступы и состояния — финальные. Воспроизводить точно.

### Типографика
- **Inter Tight** (400/500/600/700) — основной. Заголовки **строчными буквами** (правило брендбука): «модули отделов», «автоотбор товара».

- Fallback: Arial.
- Google Fonts: `family=Inter+Tight:wght@400;500;600;700&family=Geist+Mono:wght@400;500;600`

Шкала:
- H1 hero: 52px / 600 / line-height 1.02 / letter-spacing -0.03em
- H1 страницы: 44px / 600 / 1.05 / -0.03em

## Interactions & Behavior
- Сайдбар и карточки модулей → навигация на экран модуля (scroll в начало).
- «+ новая обработка» → открыть дровер. ×, «Отмена», оверлей → закрыть.
- Аккордеон: независимое раскрытие каждой секции.
- «Сбросить» — режим, каналы, категории и файл возвращаются к значениям по умолчанию.
- «Запустить обработку» (если валидно) → закрыть дровер, добавить запуск со статусом «В очереди» в начало списка, перейти на хаб.
- Hover-переходы: .15s.

## Модульность
Модули описаны одним массивом-реестром: `{ id, idx, dept, tool, title, desc, tag: 'MVP'|'ROADMAP', live }`. Сайдбар, карточки хаба и заглушки генерируются из него — новый модуль отдела = новая запись + свой роут/компонент. Рекомендуется сохранить этот паттерн в коде.
