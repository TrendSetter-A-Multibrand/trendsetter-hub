## О проекте
Хаб для всех отделов компании (РФ и Армения, один URL): общее ядро (роли, загрузка файлов, очередь задач, журнал) + модули (Закупки — MVP; WB-карточки, Аналитика, Ценообразование — roadmap).
Полная архитектура, открытые вопросы Q1–Q13 и план — в **`ARCHITECTURE.md`**. Концепция — `Платформа_инструментов_презентация.pdf`.
**Текущий этап: архитектура согласована в общих чертах, кода нет. Цель старта — только «оболочка» (этап 0: ядро, роли, хаб, заглушка модуля), без данных. Этап 1 (Закупки) не начинать, пока не определены источники данных (Q6).**

## Принципы продукта
- Человек принимает решение: платформа рекомендует и объясняет, ничего не закупает/не выставляет автоматически.
- Новый отдел = новый модуль; ядро не переделывается. Отделы — справочник в БД (добавляются без деплоя).
- Доступ: уровни `admin` / `superuser` / `employee` / `viewer`; employee полный в своём отделе, у остальных только просмотр (см. ARCHITECTURE.md, раздел 5).
- UI: боковое меню слева по брендбуку (макет — `design/`, заменил вариант 2 из PDF), только русский язык, сброса пароля по почте нет.
- Vercel — временная демо-витрина оболочки (только интерфейс, без реальных данных); данные и бэкенд позже в DO. viewer видит только интерфейс/структуру, без файлов и результатов.
- Контракт модуля: вход — файл, выход — файл или рекомендация.
- Роли, загрузка, очередь, журнал — только в ядре.

## Стек и раскладка
Backend: Python 3.13, FastAPI, SQLAlchemy 2, psycopg3, Alembic, JWT (python-jose), bcrypt. Frontend: React 19, Vite, antd 6, react-router 7, axios, **JS без TypeScript**. БД: PostgreSQL (DigitalOcean).
- Ядро: `backend/app/core/`, `frontend/src/core/`.
- Модуль: только `backend/app/modules/<id>/` и `frontend/src/modules/<id>/`. Ядро не импортирует конкретные модули, кроме списка `MODULES` в `core/registry.py`.
- Чек-лист нового модуля: манифест → строка в `MODULES` → строка в `frontend/src/modules/registry.js` → привязка к отделам (`module_departments`), права `view`/`run` через `require_access` → миграция → тесты.

## Команды
Фронтенд-оболочка (готова): `cd frontend && npm install && npm run dev` (демо-режим: `VITE_DEMO_MODE=true` в `.env.local`), `npm test`, `npm run lint` (oxlint из шаблона Vite 8), `npm run build`. Бэкенд ниже — после появления каркаса.
```
docker compose up -d postgres        # локальная БД (только dev)
cd backend && alembic upgrade head
uvicorn app.main:app --reload
python -m app.worker
cd frontend && npm run dev
pytest ; npm run lint ; npm run build
```
